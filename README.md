# Khat by shii

A little letter-writing page in my own handwriting font, [Shii](https://github.com/helloayushisharma/shii-font).

Write on checked paper, adjust size, letter spacing and line height, add stickers, photos (click the clip or tape to change it) and torn notes, then download the page as an image.

It's a single self-contained `index.html` — the font is built in, and everything you write stays in your own browser.
